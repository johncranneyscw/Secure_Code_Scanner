## Setup Steps

### 1. Clone the Repository

```bash
git clone https://github.com/rishabh16398/Secure_Code_Scanner.git
cd Secure_Code_Scanner
```

### 2. Checkout the Feature Branch

```bash
git checkout feature/scoring_system
```

### 3. Set Up Python Environment

```bash
python3 -m venv venv

# Activate the environment
# On Linux/macOS:
source venv/bin/activate

# On Windows:
venv\Scripts\activate
```

### 4. Install Python Dependencies

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 5. Install Security Scanners

```bash
# Semgrep and Bandit (straightforward)
pip install semgrep
pip install bandit

# Bearer
curl -sfL https://raw.githubusercontent.com/Bearer/bearer/main/contrib/install.sh | sh
sudo mv bearer /usr/local/bin/

# Trivy
# Ubuntu/Debian:
wget https://github.com/aquasecurity/trivy/releases/download/v0.48.0/trivy_0.48.0_Linux-64bit.deb
sudo dpkg -i trivy_0.48.0_Linux-64bit.deb

# macOS:
brew install aquasecurity/trivy/trivy

# OSV-Scanner (requires Go)
go install github.com/google/osv-scanner/cmd/osv-scanner@latest
```

### 6. Verify Installation

```bash
semgrep --version
bandit --version
bearer version
trivy --version
osv-scanner --version
```

### 7. Run the Application

```bash
python app.py
```

Access at: http://127.0.0.1:8080

## How to Use the Application

### What This Tool Does

This is an analysis dashboard for post-processing security scan results. It takes consolidated JSON files from multiple scan runs and calculates risk scores and overall security metrics.

### What You Need to Upload

**Required File:** `consolidated_all_runs_10_runs.verdicted.json`

This is a consolidated JSON file containing results from 10 security scanning runs with manual verdicts already applied.

**File size:** Usually 500KB to 50MB depending on number of findings

### File Preparation

The file you'll be uploading (`consolidated_all_runs_10_runs.verdicted.json`) has already been prepared with:

1. Results from 10 security scanning runs
2. Findings from all scanners (Semgrep, Bandit, Bearer, Trivy, OSV-Scanner)
3. Manual verdicts applied (TP = True Positive, FP = False Positive)

You just need to upload it to the dashboard.


### Using the Dashboard

1. Open http://127.0.0.1:8080 in your browser
2. Click on Analysis Mode (Upload JSON)
3. Click "Choose File" and select `consolidated_all_runs_10_runs.verdicted.json`
4. Or drag-and-drop the file onto the upload area
5. Wait for processing (typically 10-60 seconds)
6. Review the analysis dashboard with risk scores and metrics

### What Happens During Processing

The system will:
- Parse and validate your JSON file
- Extract all findings from all runs and all tools
- Normalize file paths (run_1/file.py becomes file.py)
- Filter to only True Positives (ignore False Positives)
- Group findings by programming language and CWE
- Count unique files affected per CWE
- Calculate risk scores using the formula: V × I × L × Vol × C × 100
- Compute overall model security score (0-100, higher = better)
- Generate visualizations and statistics



### Exporting Results

From the dashboard you can export:
- Excel report (recommended for analysis and sharing)
- Word document (for formal reports)
- JSON file (for programmatic access)
