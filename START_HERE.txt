================================================================================
  TROUBLESHOOTING
================================================================================

PROBLEM: "ModuleNotFoundError: No module named 'flask'"
SOLUTION: Run: pip install -r requirements.txt

PROBLEM: "Address already in use"
SOLUTION: Port 8080 is busy. Edit app.py, change port in last line

PROBLEM: "No analysis data available"
SOLUTION: Upload a JSON file first in Analysis Mode

PROBLEM: Page not loading
SOLUTION: Make sure server is running (check terminal output)

PROBLEM: JSON upload fails
SOLUTION: Verify JSON has "runs" array with proper structure
