📊 Model-Level Score Calculation

Formula:
Final Score = (100 - Composite Risk) × 0.7 + Density Score × 0.3
Step-by-Step:
1. Composite Risk =
  0.4 × Top5_Avg + 0.3 × Weighted_Avg + 0.3 × Max_Risk
  = 0.4 × {{ analysis.model_score.components.critical_penalty }} + 0.3 × {{ analysis.model_score.components.weighted_avg_risk }} + 0.3 × {{ analysis.model_score.components.max_risk }}
  = {{ (analysis.model_score.components.critical_penalty * 0.4)|round(2) }} + {{ (analysis.model_score.components.weighted_avg_risk * 0.3)|round(2) }} + {{ (analysis.model_score.components.max_risk * 0.3)|round(2) }}
  = {{ analysis.model_score.components.composite_risk }}
2. Security Score =
  100 - Composite Risk
  = 100 - {{ analysis.model_score.components.composite_risk }}
  = {{ (100 - analysis.model_score.components.composite_risk)|round(2) }}
3. Final Score =
  Security Score × 0.7 + Density Score × 0.3
  = {{ (100 - analysis.model_score.components.composite_risk)|round(2) }} × 0.7 + {{ analysis.model_score.components.density_score }} × 0.3
  = {{ ((100 - analysis.model_score.components.composite_risk) * 0.7)|round(2) }} + {{ (analysis.model_score.components.density_score * 0.3)|round(2) }}
  = {{ analysis.model_score.final_score }}/100
